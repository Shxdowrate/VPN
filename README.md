# VPN

Свой минималистичный VPN-клиент для Windows на движке [sing-box](https://github.com/SagerNet/sing-box).

- Одна большая кнопка, справа — скорость, пинг, потери, трафик и время сессии.
- Серверы из подписки внизу, с пингом; «Авто» сам выбирает самый быстрый, переключение — на лету.
- **Раздельное туннелирование** (меню слева → «Туннели»):
  - что делать со всем остальным трафиком: через VPN или напрямую;
  - программы: выбери из запущенных или через «Обзор…», для каждой — через VPN или напрямую;
  - сайты: `youtube.com` через VPN, `vk.com` напрямую и т. п.;
  - «Российские сайты напрямую» и «Блокировать рекламу».
- Подписка обновляется сама, показывает остаток трафика и срок.
- Трей, автозапуск с Windows, автоподключение.

## Установка
Скачай архив из **Actions** (последний запуск → `VPN-windows-x64`) или из **Releases**, распакуй в любую папку и запусти `VPN.exe`.
Программа просит права администратора: без них Windows не даёт создать виртуальный сетевой адаптер.

Данные (настройки, журнал) лежат в `%LocalAppData%\ShxdowrateVPN`.
