# Neon VPN

VPN-клиент для Windows в духе Happ, но со своими фишками: **два ядра** (sing-box и Xray), удобное раздельное туннелирование,
несколько подписок со своими группами, «Авто» и кнопка «Лучший», раздельная статистика VPN / напрямую и неоновый интерфейс
с окном нестандартной формы.

## Что умеет

**Ядра.** sing-box всегда стоит «на входе» (TUN, системный прокси, правила, счётчики), а с сервером разговаривает выбранное ядро:

```
программы → TUN / системный прокси → sing-box: DNS, правила туннелей, статистика
                                        ├─ напрямую
                                        └─ сервер ── ядро sing-box: сразу к серверу
                                                  └─ ядро Xray: socks 127.0.0.1 → Xray → сервер
```

Что одно ядро не умеет, берёт другое: xhttp/mKCP/VLESS Encryption — всегда через Xray, Hysteria2 и TUIC — через sing-box.
Для мобильного интернета есть фрагментация TLS (Xray).

**Протоколы:** VLESS (Reality, TLS, tcp/ws/grpc/httpupgrade/xhttp), VMess, Trojan, Shadowsocks, Hysteria2, TUIC, SOCKS.

**Режимы:** TUN (весь трафик системы), системный прокси Windows или оба сразу. Можно пустить устройства из локальной сети.

**Серверы и подписки**
- сколько угодно подписок + свои серверы ссылками («Мои серверы»);
- у каждого сервера галочка: снял — сервер не участвует в «Авто» и «Лучшем», и выбор переживает обновления подписки;
  можно сделать так, чтобы новые серверы из обновлений приходили выключенными;
- свои группы из серверов любых подписок («Игры», «Европа»…);
- пинг настоящим запросом через сам сервер, сортировка по пингу, поиск.

**Выбор сервера**
- **Авто** — среди всех серверов, одной подписки или одной группы. Перепроверяет каждые N минут, переходит, только если новый
  быстрее на заданный порог; если сервер замолчал на ~10 секунд, а интернет напрямую есть — уходит сразу.
- **Лучший** — пингует область (всё, подписку, группу или выделенные серверы), подключает самый быстрый и **фиксирует** его:
  дальше сервер сам не меняется.
- Ручной выбор — двойной клик; переключение без переподключения.

**Раздельное туннелирование:** программы, сайты (с поддоменами, кириллица тоже) и IP/подсети — через VPN, напрямую или блок;
«всё остальное» — через VPN или напрямую; готовые правила: российские сайты напрямую, локальная сеть напрямую, блокировка рекламы.
Добавить программу можно из запущенных или через «Обзор…». Применяется сразу.

**Статистика отдельно для VPN и прямого трафика:** скорость загрузки/отдачи с графиком, пинг (последний и средний),
джиттер, потери за последние 20 проверок, число соединений, трафик за сессию.

**Интерфейс:** тёмный неон без системной рамки — силуэт окна со срезами и ступеньками (Клинок / Осколок / Капсула),
светящийся контур с бегущим переливом, 7 цветовых схем, регулируемая яркость. Кнопка мини-окна: остаётся кнопка вкл/выкл,
сервер, скорость, пинг и потери для VPN и напрямую. Трей с меню (Авто по области, выбор сервера), Ctrl+Alt+V — вкл/выкл
откуда угодно, автозапуск через Планировщик (без окна UAC).

## Установка

Скачай архив из **Actions** (последний запуск → `VPN-windows-x64`) или из **Releases**, распакуй и запусти `VPN.exe`.
Программа просит права администратора: без них Windows не даёт создать виртуальный адаптер (TUN).

Данные лежат в `%LocalAppData%\NeonVPN`. Подписка и правила из прошлой версии (`ShxdowrateVPN`) переносятся сами при первом запуске.

## Устройство кода

- `src/Vpn.Core` — вся логика без привязки к Windows: разбор ссылок, подписки, конфиги sing-box и Xray, запуск ядер,
  пинги, «Авто»/«Лучший», раздельная статистика.
- `src/Vpn.App` — окно на WPF, трей, системный прокси, автозапуск.
- `tests/CoreCheck` — разбор ссылок всех видов и сборка конфигов; CI проверяет их настоящими `sing-box check` и `xray run -test`.
- `tests/LiveCheck` — живая проверка на Linux с настоящими ядрами и локальными тестовыми серверами (`server.json`, `target.py`):
  пинги, «Лучший», «Авто» по группе, ручной выбор, раздельный счёт трафика, пинг/потери, подъём после падения ядра — для обоих ядер.
