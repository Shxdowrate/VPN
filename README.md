# VPN

Свой минималистичный VPN-клиент для Windows на движке [sing-box](https://github.com/SagerNet/sing-box).

- Минималистичное тёмное окно необычной формы: слева рельса разделов, справа — приподнятая колонка с большой кнопкой.
  По кромке окна бежит неоновый свет, и его цвет говорит о состоянии: фиолетово-синий — отключено, янтарный — подключение,
  зелёно-бирюзовый — подключено (с лаймовым или тёплым оттенком, если пинг растёт), красный — ошибка.
- Одна большая кнопка со «шкалой» как на видеокартах, под ней — внешний IP и страна (через VPN), ниже — скорость, пинг, потери, трафик и время сессии.
- **Несколько подписок сразу**: серверы сгруппированы по подпискам, у каждой — свой остаток трафика и срок. Избранное (★) — отдельной группой сверху,
  у серверов — цветные метки протоколов и светящаяся точка пинга. «Авто» сам выбирает самый быстрый.
- **Импорт как в Happ**: скопируй ссылку и нажми Ctrl + V в окне (или программа сама предложит, увидев её в буфере). Понимает
  подписки `https://…`, серверы `vless:// vmess:// trojan:// ss:// hysteria2:// tuic:// socks://`, ссылки-обёртки `happ://add/…`,
  `sing-box://`, `hiddify://`, `v2raytun://`, а кнопки «Добавить в Happ» на сайтах панелей открывают эту программу.
  Зашифрованные ссылки `happ://crypt…` открывает только сам Happ.
- **Профили маршрутизации**: свои наборы правил («Дом», «Игры»…), переключение в один клик — в «Туннелях», с главного экрана и из трея.
  Профили Happ (`happ://routing/…`) импортируются: geosite/geoip, домены и IP превращаются в правила.
- **Раздельное туннелирование** (раздел «Туннели»):
  - всё остальное — через VPN или напрямую;
  - одна строка понимает всё: `youtube.com`, `discord.exe`, `1.2.3.0/24`, `geosite:twitch` — и Enter; для каждого — через VPN, напрямую или блок;
  - программы — из запущенных, через «Найти exe…» или просто перетащи `.exe`/ярлык в окно; сайт — перетащи ссылку из браузера;
  - готовые наборы: YouTube, Discord, Telegram (с IP-адресами), ChatGPT, Claude, Netflix, Twitch…;
  - «Российские сайты напрямую» и «Блокировать рекламу». Наборы geosite/geoip скачиваются сами при добавлении.
- Понятные статусы, переподключение при обрыве, уведомления Windows, смена сервера и профиля из трея,
  Ctrl + Alt + V — включить/выключить VPN откуда угодно, окно можно закрепить поверх остальных.
- Трей, автозапуск с Windows, автоподключение. Настройки старой версии переносятся сами.

## Установка
Скачай архив из **Actions** (последний запуск → `VPN-windows-x64`) или из **Releases**, распакуй в любую папку и запусти `VPN.exe`.
Программа просит права администратора: без них Windows не даёт создать виртуальный сетевой адаптер.

Данные (настройки, журнал) лежат в `%LocalAppData%\ShxdowrateVPN`.
