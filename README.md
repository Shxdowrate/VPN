# VPN

Свой минималистичный VPN-клиент для Windows на движке [sing-box](https://github.com/SagerNet/sing-box).

- Компактное окно размером со смартфон и необычной формы: корпус с «капсулой» статуса сверху и плавающий док снизу.
  Разделы (серверы, туннели, подписка, настройки) выезжают панелью слева, рядом с «телефоном». Окно можно растянуть, оно запоминает место.
- Одна большая кнопка, под ней — внешний IP и страна (через VPN), ниже — скорость, пинг, потери, трафик и время сессии.
- Понятные статусы: подключение, подключено, смена сервера, переподключение, нет ответа, ошибка — на кнопке, в капсуле и цветом значка в трее.
- Серверы из подписки с пингом, избранное (★) и сортировка по пингу; «Авто» сам выбирает самый быстрый.
  Смена сервера на лету — с подтверждением и новым пингом; если «Авто» сам перешёл на другой сервер, программа об этом скажет.
- Если связь оборвалась — сама переподключается. Уведомления Windows, когда окно скрыто.
- Сервер можно сменить прямо из меню трея; Ctrl + Alt + V — включить/выключить VPN откуда угодно; окно можно закрепить поверх остальных.
- **Раздельное туннелирование** (док внизу → «Туннели»):
  - что делать со всем остальным трафиком: через VPN или напрямую;
  - программы: выбери из запущенных или через «Обзор…», для каждой — через VPN или напрямую;
  - сайты: `youtube.com` через VPN, `vk.com` напрямую и т. п.;
  - «Российские сайты напрямую» и «Блокировать рекламу».
- Подписка обновляется сама, показывает остаток трафика и срок.
- Трей, автозапуск с Windows, автоподключение.

## Установка
Скачай архив из **Actions** (последний запуск → `VPN-windows-x64`) или из **Releases**, распакуй в любую папку и запусти `VPN.exe`.
Программа просит права администратора: без них Windows не даёт создать виртуальный сетевой адаптер.

Данные (настройки, журнал) лежат в `%LocalAppData%\ShxdowrateVPN`.
